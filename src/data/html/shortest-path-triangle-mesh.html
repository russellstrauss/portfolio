Shortest Path on a Triangle Mesh computes geodesic paths on 3D surfaces represented as triangle meshes. Unlike straight-line distance in the plane, the shortest path between two points on a mesh follows the surface geometry—crossing edges and traversing triangles—so the result is a path that stays on the mesh and minimizes total path length.

This project implements and visualizes algorithms for finding such paths, commonly used in geometry processing, character animation, and procedural mesh operations. The featured image illustrates a computed path on a triangulated surface.
